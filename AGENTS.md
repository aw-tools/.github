# Agent instructions

Working rules for the `aw-tools` organisation's default community health files.

## Delivery

Trunk-based. Signed commits straight to `trunk`, then push. No branch, no pull
request.

## What lives here

Files GitHub applies to every public `aw-tools` repository that lacks its own
copy. A repository's own file always wins, so a file here covers only the
repositories that carry none.

## Before every push

Show the change and wait for a go.
